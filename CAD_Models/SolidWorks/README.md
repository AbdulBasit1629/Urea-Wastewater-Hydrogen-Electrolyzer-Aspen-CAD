# SolidWorks Native Files

Upload the original SolidWorks source files in this folder.

## Expected artifacts

- Main electrolyzer assembly: `.SLDASM`
- Referenced component parts: `.SLDPRT`
- Supporting SolidWorks assemblies/parts used by the main model

## Upload guidance

Preserve the original filenames where practical. Because a SolidWorks assembly references component files, upload the complete set of dependent `.SLDPRT` files together with the `.SLDASM` assembly.

These native files are the primary CAD source artifacts for the project.
