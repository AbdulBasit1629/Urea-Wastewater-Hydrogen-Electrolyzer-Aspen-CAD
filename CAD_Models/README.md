# CAD Models

Phase 2 of the project repository: SolidWorks engineering artifacts for the proposed twin-chamber urea wastewater electrolyzer.

## Planned contents

- Native SolidWorks assembly (`.SLDASM`)
- Native SolidWorks part files (`.SLDPRT`)
- Universal CAD exports (`.STEP`)
- Optional mesh exports (`.STL`)
- Engineering drawings and dimensional documentation

## Source-design basis

The CAD documentation will cover the proposed 2.4 L twin-chamber electrolyzer concept, including the electrode architecture, separator/gasket arrangement, stack compression hardware, busbars, manifolds, and other modeled components.

Native files will be retained as source artifacts. STEP/STL exports will be provided where available so reviewers without SolidWorks can inspect the geometry.

> CAD artifacts in this folder represent the submitted design files and should be treated as engineering source documents unless a file is explicitly identified as a manufactured/experimentally validated component.
